# بوت توجيه الدعم + إدارة الفريق

لوحتان ثابتتان ومثبّتتان في السيرفر، وكل شي بالعربي عدا أسماء الأوامر (متطلبات ديسكورد):

1. **`/support`** — يوجّه الأعضاء من روم الانتظار إلى إداري متاح، ويرسل طلب تقييم عند دخول "روم الانتهاء".
2. **`/manage-support`** — إدارة الفريق: تسجيل دخول/خروج، احتساب نقاط لكل ساعة كاملة، ولوحة متصدرين — أساس لنظام إدارة أكبر تقدر تبني عليه لاحقًا.

كلا اللوحتين تُنشر كرسالة عادية (غير مؤقتة) وتُثبَّت تلقائيًا. اختيار أي خيار من القائمة **لا يمسح أو يعدّل اللوحة** — يرد على الشخص بشكل خاص فقط.

## 1. إعداد البوت في Discord Developer Portal
1. روح إلى https://discord.com/developers/applications وأنشئ تطبيق جديد.
2. من تبويب **Bot** فعّل **Server Members Intent**.
3. انسخ **Token** الخاص بالبوت.
4. من **General Information** انسخ **Application ID** (هذا CLIENT_ID).
5. ادعُ البوت عبر OAuth2 → URL Generator. الـ Scopes: `bot`, `applications.commands`.
   الصلاحيات المطلوبة: `Move Members`, `Send Messages`, `View Channels`, `Manage Messages` (ضرورية للتثبيت وحذف اللوحة القديمة), `Embed Links`, `Attach Files`.

## 2. التثبيت محليًا
```bash
npm install
cp .env.example .env
```
عبّي `.env` بـ `DISCORD_TOKEN`, `CLIENT_ID`, `GUILD_ID`.

## 3. إضافة صورتك (اختياري)
حط صورة باسم `banner.png` بالضبط داخل مجلد `assets/`. بتظهر تلقائيًا في كلا اللوحتين. لو ما حطيت صورة، يشتغل البوت عادي بدونها.

## 4. تسجيل الأوامر وتشغيل البوت
```bash
npm run deploy   # يسجل /support و /manage-support
npm start
```

## 5. طريقة الاستخدام

### `/support` — لوحة توجيه الدعم
شغّله مرة وحدة بالروم اللي تبي اللوحة تكون فيه. الخيارات:

| الخيار | لمن | الوظيفة |
|---|---|---|
| ✅ متاح | الجميع | يمكن سحب أعضاء إليك |
| ⛔ مشغول | الجميع | ما ينسحب لك أحد |
| 🎯 عيّني على غرفة | الجميع | اختر غرفة + رومك الشخصي |
| 🚫 الغِ تعييني من غرفة | الجميع | احذف تعيين |
| 📋 حالتي | الجميع | اعرض حالتك وتعييناتك |
| 📂 كل الغرف | الجميع | اعرض كل الغرف المُعدة |
| 🛠️ إنشاء / تعديل غرفة | المشرفين | نموذج للمفتاح + الاسم، ثم اختيار روم الانتظار |
| 🗑️ حذف غرفة | المشرفين | اختر غرفة لحذفها |
| 🏁 تحديد روم الانتهاء | المشرفين | حدد الروم الصوتي الذي إذا دخله العضو يُطلب منه تقييم الخدمة |

### 🏁 نظام "روم الانتهاء" والتقييم
بعد ما يخلص الإداري من مساعدة العضو، ينقله (يسحبه يدويًا) إلى الروم المحدد كـ"روم الانتهاء". بمجرد ما يدخله العضو:
- يوصله **رسالة خاصة** فيها: "انتهت خدمتك ✅، نحتاج تقييمك وملاحظاتك إن وجدت".
- يختار تقييمه من ⭐ إلى ⭐⭐⭐⭐⭐ بالأزرار.
- تفتح له نافذة صغيرة (اختيارية) يكتب فيها ملاحظاته.
- يقدر المشرفين مراجعة آخر 10 تقييمات من خيار **"📝 آخر التقييمات"** داخل لوحة `/manage-support`.

⚠️ **مهم:** لازم يكون خاص العضو (DMs) مفتوح من إعدادات الخصوصية عشان توصله الرسالة، وإلا ما راح يستقبلها.

### `/manage-support` — لوحة إدارة الفريق
فقط المشرفين (صلاحية Manage Server) يقدرون يشغّلون هذا الأمر لنشر اللوحة، لكن أي عضو له صلاحية رؤية الروم يقدر يستخدمها:

| الخيار | لمن | الوظيفة |
|---|---|---|
| 🟢 تسجيل دخول | الجميع | يبدأ جلسة العمل |
| 🔴 تسجيل خروج | الجميع | ينهي الجلسة ويحتسب النقاط |
| 📊 ساعاتي ونقاطي | الجميع | يعرض إجمالي الوقت والنقاط لحظيًا |
| 🏆 المتصدرين | الجميع | أفضل 10 أعضاء بالنقاط |
| ⚙️ تحديد معدل النقاط | المشرفين | كم نقطة لكل ساعة كاملة (افتراضي: 1) |
| 📝 آخر التقييمات | المشرفين | آخر 10 تقييمات وصلت من نظام روم الانتهاء |

النقاط تُحتسب فقط على **الساعات الكاملة المكتملة** — مثلًا جلسة ساعتين و45 دقيقة تحسب نقاط ساعتين فقط.

## إعادة تشغيل الأوامر
لو شغّلت `/support` أو `/manage-support` مرة ثانية بنفس الروم، البوت يحذف/يفك تثبيت اللوحة القديمة وينشر وحدة جديدة — عشان ما تتكرر اللوحات.

## ملاحظات
- البيانات تُخزّن محليًا بملفات JSON داخل `data/` (الغرف، تعيينات الإداريين، مواقع اللوحات، الحضور، إعدادات النقاط، التقييمات).
- هذا أساس قابل للتوسيع — تقدر تضيف مميزات إدارية أكثر (رتب، إنذارات، جدولة الورديات...) على نفس لوحة `/manage-support` بدون ما يأثر على الموجود.
- تأكد إن البوت عنده صلاحية **Manage Messages** بأي روم تنشر فيه لوحة، وإلا التثبيت والتنظيف ما يشتغلون (باقي الميزات تشتغل عادي).
